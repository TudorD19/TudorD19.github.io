Load balancer simulation

This is the behaviour of the load balancer project, rebuilt as a small model you can run here. Clients connect to one virtual IP. The balancer hands new connections to the servers in turn and keeps each connection on the server it started with. When a server is taken offline, new connections skip it, and a connection that was mapped to it gets a new server on its next packet.

  1. Start the traffic and watch connections spread across the three servers.
  2. Take a server offline. New connections skip it, and its connections get a new server as their next packets arrive.
  3. Bring it back online. It returns to the round-robin pool, and new connections reach it again.
